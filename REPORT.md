# REPORT: Long-Tail Destination Network

Every number in this report links to the file that holds it. Those files are written by scripts, never by hand.
The per-claim status (Yes / Partial / No) is in [`evidence/LEDGER.md`](evidence/LEDGER.md), generated by
`scripts/prove_all.sh`. Where a number will be refreshed by the final proof run, the text says so with a marker.

## 1. What was built
One FastAPI service (API + worker, one image) with Postgres as both the database and the job queue, and
S3-compatible storage. It contains:
- **Nine connectors behind the IncuBrix contract:**
  - Six Core: Discourse, Lemmy, Dev.to, Ghost, a signed HMAC webhook and assisted packs.
  - Three Advanced: Slack, PeerTube and a Media RSS feed.
- **A deterministic posting-rules engine** that runs before every post.
- **Tailoring** per destination.
- **A certification harness** with trust levels L0–L4, a test-post sweeper, recertification, demotion and alerts.
- **Catalogue tools:** import, relevance, rules capture with human confirmation.
- **A recommender** and normalised metrics.

`docker compose up` starts the service together with **real local Lemmy and Ghost** (plus real Discourse and
PeerTube under optional profiles). It also starts **faithful mocks** for every platform, with fault injection.

## 2. Approaches considered, and why this one
| Decision | Considered | Chosen, and why |
|---|---|---|
| Language | TypeScript/NestJS; Python/FastAPI | **Python 3.12 + FastAPI + Pydantic v2.** Strict response models make a renamed platform field a validation error, which fails certification by construction. OpenAPI 3.1 comes for free. One language serves the API, worker, mocks, batch runner and tests ([ADR 0001](docs/adr/0001-python-fastapi.md)). |
| Queue and locks | Redis + Celery; Postgres | **Postgres only** (SKIP LOCKED, LISTEN/NOTIFY, advisory locks). A job row and its idempotency row commit in one transaction. There is one fewer service to run, and it fits a free host ([ADR 0002](docs/adr/0002-postgres-queue.md)). |
| Never double-post | trust the platform's idempotency; outbox; **write-ahead intent + marker** | Most long-tail platforms have no idempotency key. We record a PENDING intent **before** the call and put an invisible marker in the post. After a timeout or a 5xx, the retry finds the post by its marker instead of posting again ([ADR 0003](docs/adr/0003-write-ahead-publish-intent.md)). |
| Rules | an LLM judges each post; **deterministic checks** | Pure code with a decision table ([docs/RULES.md](docs/RULES.md)). It is predictable, testable and explainable. The LLM only *proposes* rules from a rules page, and a person confirms them ([ADR 0004](docs/adr/0004-rules-gate-order.md), [ADR 0008](docs/adr/0008-free-llm-chain-quote-verification.md)). |
| No rules known on a contract call | refuse; conservative default; **allow + warn** | IncuBrix's contract suite sends bare Appendix A destinations, so the contract `publish` is allowed: spec checks still run, and it warns `rules_source=none_supplied`. Our own publication API still requires confirmed rules and a certified destination ([ADR 0005](docs/adr/0005-d9-no-rules-default.md)). |
| Test platforms | real accounts; mocks only; **mocks + real local instances** | Real Lemmy and Ghost run in compose on an internal network with no internet route, so real end-to-end posts are possible with no risk to any community. Mocks were checked against responses recorded from the real containers ([ADR 0007](docs/adr/0007-mocks-and-real-instances.md)). |
| Dev.to | claim delete; skip; **L2 with the limitation documented** | The Forem API has no delete. We unpublish (to draft) and never report `deleted: true` ([ADR 0006](docs/adr/0006-devto-level-2.md)). |
| AI | paid model; **free chain with a mock default** | Gemini free tier → Groq → OpenRouter `:free` → local Ollama → deterministic mock, behind one OpenAI-compatible adapter. The output must follow a strict schema, and every quote must appear verbatim on the page ([ADR 0008](docs/adr/0008-free-llm-chain-quote-verification.md)). |
| Live demo | VPS; Vercel; **Render free + Supabase free** | Vercel is serverless with no worker. The free tier allows one container, so the demo is an all-in-one process (API + worker + mocks, simulation only) ([ADR 0009](docs/adr/0009-render-supabase-demo.md)). |

- **Contract.**
  - Every connector serves the Appendix A methods with exactly the Appendix A keys.
  - Every connector has a schema-checked manifest and maps to shared error codes.
  - Unsupported methods answer `404 METHOD_NOT_SUPPORTED`.
  - When the same post id exists on two instances, it now comes back tagged with its instance.
  - Evidence: `scripts/prove_mh1.sh` → `evidence/must_haves/MH1_contract.log`, `MH1_contract_matrix.csv`.
- **Certification.**
  - The six Core connectors pass on the mocks.
  - **Real** Lemmy passes at L4 (publish, live, status, metrics, purge) and **real** Ghost at L3.
  - Evidence: [`evidence/metrics/certification_runs.csv`](evidence/metrics/certification_runs.csv) and packs in `evidence/certification/`.
  - Real PeerTube v8.3.0 certified at L4, and Slack at L4 on its mock: `evidence/connectors/P4C/`.
- **One row = one destination.** A JSON or CSV row with no connection and no code certifies for every connector type: `evidence/must_haves/MH3_add_*.log`.
- **Rules before every post.**
  - The rule test set has **113 cases: 83 violations caught, 0 missed, 30 correct allows, 0 false positives** ([`evidence/metrics/rule_safety.csv`](evidence/metrics/rule_safety.csv)).
  - A second post inside a weekly cap is rescheduled with `retry_at` and `Retry-After`. A promotional post to a no-promotion destination is blocked, and the error names the signal that fired.
- **Safe retries.**
  - **0 duplicates** in 17 timeout/retry scenarios, including real Lemmy and Ghost behind toxiproxy ([`duplicates_under_retry.csv`](evidence/metrics/duplicates_under_retry.csv)).
  - 40 parallel publishes: 40×200, 40 platform posts, 40/40 replays ([`M6_parallel_publish.txt`](evidence/integration/M6_parallel_publish.txt)).
- **Never spam.**
  - Test posts go only to own hosts; a real host is refused at PREFLIGHT before anything is sent.
  - The sweeper removes test posts after 300 s. The audit counts `deleted`, `soft_deleted` and `unpublished_to_draft` **separately**.
  - 429 handling uses the platform's reset time, and the next call short-circuits with no platform call.
  - Evidence: `evidence/must_haves/MH5_*`.
- **Secrets.** A canary token, the bootstrap secrets and gitleaks found 0 real secrets in logs, evidence or the tree (`evidence/must_haves/MH7_*`).
- **Integration Standard.**
  - `scripts/integration_selfcheck.sh` passes 7/7 automated checks on a running stack (IS2–IS6, IS8, IS10) (`evidence/integration/IS_selfcheck.txt`).
  - IS7 files in and out and the IS9 manifest are proven by `scripts/prove_mh9.sh`.
  - The batch runner sample pack passed 20/20 on 2026-10-20.
- **Advanced.**
  - **Catalogue import:** 1,000 rows in **68.2 / 117.3 / 72.1 s** over 3 runs (target < 300 s), with every row matching its expected outcome ([`catalogue_import.csv`](evidence/metrics/catalogue_import.csv)).
  - **Rules capture:** the AI step proposes rules with quotes and confirmation is a separate step (`evidence/advanced/ADV2_proposal_confirm.log`).
  - **Relevance** 1–5 with a reason: 86.4 % within ±1 of the labels ([`ADV3_relevance_summary.csv`](evidence/levels/adv/ADV3_relevance_summary.csv); labels agent-drafted, see §4).
  - **Tailoring:** forum, article, Slack, newsletter and MRSS profiles, with property-tested word-boundary truncation.
  - **Three more connectors:** Slack, PeerTube and MRSS.
- **Outstanding.**
  - **Metrics** normalised on 4 connectors, 2 of them real local instances ([`OUT2_metrics.csv`](evidence/levels/out/OUT2_metrics.csv)).
  - **Recertification:** a clock jump past 21 days re-tests destinations; a broken one is demoted, excluded and alerted (HMAC-verified webhook plus an emulated GitHub issue), then restored once it passes ([`OUT3_recert.log`](evidence/levels/out/OUT3_recert.log)).
  - **Recommender:** test P@10 **0.45** against BM25 0.24 and random 0.04 ([`OUT1_precision.json`](evidence/levels/out/OUT1_precision.json); labels agent-drafted, see §4).

## 4. What does not work, or only partly, and why
1. **Dev.to has no delete.**
   - The Forem API v1 has no article DELETE, and `/unpublish` needs a moderator or admin. We revert to draft and wipe the text.
   - Dev.to is therefore certified at **L2**, never L3, and is never reported as `deleted: true`.
   - The real dev.to was **never called**: no key was provided. The connector supports a draft-only run.
2. **Discourse.**
   - The default compose uses a Discourse mock that matches recorded real responses.
   - The real Discourse runs only under `--profile full` (about 2 min and 1.3 GB). Its live connector tests passed 3 of 3 times.
   - No harness certification run on the real Discourse is in the evidence.
   - Deletion is a **soft delete** (public 404, the admin can still read it) and is labelled `soft_deleted` everywhere.
   - Not measured on the real Discourse: the 429 body, and the review-queue JSON.
3. **Real Slack** was never called (no workspace token). Its L4 is on a mock that follows Slack's docs.
4. **The labels are AI-drafted.**
   - The 895 recommender labels and the 59 relevance labels were drafted by an AI agent. They are marked `labeler=agent-draft` and are **pending human review**.
   - The same agent wrote the rubric, the items and the recommender, so P@10 favours the recommender by design.
   - The number must be read with that caveat until a person reviews the labels (`uv run python -m app.tools.label review --reviewer <name>`, then `uv run python -m app.recommender.eval --print`).
   <!-- TODO(final-numbers): P@10 after human review, if done -->
5. **The real catalogue (OUT4) was researched with AI help.**
   - The deterministic extractor found verifiable rules on only 9 of 145 real pages ([`real_catalogue_report.md`](catalogue/reports/real_catalogue_report.md)).
   - An AI agent therefore researched the rules pages. Every value is backed by a quote of ≤25 words, and a script verified each quote verbatim against the saved page text ([`catalogue/research/README.md`](catalogue/research/README.md), `scripts/prove_out4_research.py`).
   - **No person has confirmed these rules yet.** Every row stays `proposed` and cannot be posted to until it is confirmed.
   - Mastodon servers (one of the brief's out-of-scope major platforms) are excluded from the count, and Discourse categories are reported separately from distinct forums and communities.
   - <!-- TODO(final-numbers): final counted rows from prove_out4_research.py after the final research run -->
6. **A local LLM is worse than deterministic code.**
   - On our 22 rules pages, the free local `qwen2.5:1.5b-instruct` on CPU scored 0.50 field accuracy after the quote check. The deterministic extractor scored 0.83, and the 1.5B model invented 12 false rules.
   - Relevance with that model was not better either: it moved scores down without real judgement.
   - The default provider is therefore the deterministic `mock`.
   - Even a strong model only *proposes* rules. Quote verification replaces any value whose quote is not on the page with a conservative default.
   - <!-- TODO(final-numbers): ollama + gemini rows must be regenerated in evidence/metrics/rules_capture_eval_summary.csv (a later run overwrote it with mock-only); cite them here -->
7. **Smaller limits** (all documented in the code):
   - The SSRF guard checks every hop, but a DNS-rebinding window remains.
   - Per-host politeness and the LLM cooldowns are per process.
   - Reconciliation scans the newest 50 Lemmy posts, 25 PeerTube videos and 100 Slack messages. An account that posts more than that between a timeout and its retry could be missed.
   - The language guesser is heuristic. Disclosure translations were written by AI and need a native-speaker review.
   - A paused webhook connection cannot be refreshed: a new connection is needed after a partner restores access.
   - The live demo is simulation-only (mocks in-process). Real Lemmy and Ghost runs are the compose stack's job.

## 6. Cost per 1,000 publications (computed)
cost per 1,000 = 1,000 × (platform API cost + LLM tokens × price per token) + infrastructure.
- **Platform APIs.** Lemmy, Ghost, Discourse, the Forem API, the Slack Web API, PeerTube, the webhook and the feed are all free to call: **$0**.
- **LLM per publication.**
  - The publication path (rules gate → tailoring → connector) makes **no LLM call**. Tailoring is deterministic.
  - The LLM is used only once per *destination*, during rules capture, and optionally to phrase recommendation reasons.
  - Tokens per publication = 0. At any price, the LLM cost is **$0**.
  - The job manifests record `cost.total_usd` from `LLM_PRICE_PER_1K_TOKENS_USD`. That is 0 for the free providers and the mock.
- **One-off LLM cost per destination** (rules capture): $0 on the free tiers.
  <!-- TODO(final-numbers): Gemini tokens per capture from the eval -->
- **Infrastructure.** The demo runs on free tiers (Render free, Supabase free): **$0**. The free tiers' limits (sleep when idle, 512 MB RAM) bound throughput, not cost.

**Total: $0.00 per 1,000 publications.** The only real resource is time:
- a publish on a local instance takes milliseconds to seconds (the certification run times above);
- importing 1,000 catalogue rows takes 68–117 s.

## 7. What I would do next
1. **Close the honesty gaps.** A person reviews the 895 + 59 labels and confirms at least 150 researched catalogue rows in the confirm UI. Then re-run the evals.
2. **Measure Gemini** on the rules-page eval. Switch `LLM_PROVIDER=auto` only if it beats the deterministic extractor after quote verification.
3. **Hashnode and Kit** connectors from the template.
4. **Learning from results.**
   - Feed moderator removals back into tighter caps.
   - Use cross-creator yield priors in the recommender.
   - Add automated discovery of new destinations ([docs/VISION.md](docs/VISION.md)).
5. **Scale.**
   - Partition the queue per connector.
   - Share per-host pacing across workers.
   - Pin DNS between the SSRF check and the connection.
