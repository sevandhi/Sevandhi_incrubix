PeerTube, this instance is - for the public - not bound to any topic. It was set up in January 2021.

For registration you need a valid mail address. NO TEMPORARY MAIL ADDRESSES are supported.

This site does not tolerate misinformation, fake data, etc. 

Please report abuse to the owner peertube@mail.xy-space.de

Please note that importing content from YouTube (LLC) directly, currently is disabled.

ALL videos are container encrypted.
