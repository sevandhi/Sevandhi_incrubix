# seed_v3 changelog

Generated by the catalogue research scripts (kept outside the repo) on 2026-10-20T07:24:12Z from `seed_v2.csv` (unchanged) to `seed_v3.csv`.

seed_v3 = the 175 seed_v2 rows (same order, same values) + 102 new rows added by the rules research. Two columns of seed_v2 were not present before and are added: `row_origin` (`seed_v2` or `research_v3`), `relevance_score`/`relevance_reason` (filled for new rows, and for the 9 seed_v2 rows that could not be imported and so never got a relevance score).

## Rules are NOT in this file

New rows leave the five rule columns blank on purpose. Their researched rules are in `catalogue/research/rules_research_v1.csv`, each value backed by a verbatim quote, and stay `proposed` until a person confirms them (D6). Importing seed_v3 with the rule columns would store them as confirmed (finding F1), so do not.

## How the new rows were found

- **Lemmy communities (18):** each instance's own community search API (`/api/v3/search?type_=Communities&listing_type=Local`) with generic terms (ai, video, marketing, startup, podcast, creator, ...); the exact search URL is in `discovered_via`. Only instances whose instance-wide rules are machine-readable and quote-able were searched (lemmy.ml, programming.dev, feddit.org, lemmy.ca, lemmy.zip).

- **Discourse forums (24):** direct read-only probe of `/about.json`, `/tos`, `/categories.json` and `/` of known AI / no-code / creator-tool forums (`discovered_via` says so). Forums whose robots.txt disallowed our user agent were dropped without fetching.

- **Discourse categories (43):** showcase / share / tutorial categories of forums already in the catalogue, from that forum's `/categories.json`. A category is a distinct posting destination (surface `category`) with its own description; the forum's terms still apply.

- **Mastodon servers (17):** direct probe of `/api/v1/instance` (the server rules shown on `/about`). connector `assisted` (a person posts from an account there), level ceiling L1. General-purpose servers were labelled `general` and score 1-2, so they are kept for their rules but do not count.

- Web search (generic terms only) was tried for forum guidelines; it surfaced the DeepLearning.AI self-promotion topic used for a seed_v2 row, but no new rows came from it.

## Relevance of new rows

`relevance_score` comes from the repo's own deterministic scorer `app.catalogue.relevance.lexicon_score` (the catalogue import's scorer), fed with the name, the page/community description and a category + audience tags chosen by the agent. The tags are agent judgement and are pending human review (like D11).
