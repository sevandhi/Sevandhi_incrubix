# ADR 0009: Live demo on Render free + Supabase free (all-in-one, simulation only)

Status: accepted (human decision D2).

## Context
- Must-have 9 requires a live demo that works for the whole review period, with a rate limit, at no cost.
- Vercel is serverless and cannot run a worker. Railway's free plan is too small.
- Render free gives one container (512 MB, sleeps when idle). Supabase free gives Postgres and S3-compatible
  Storage.

## Decision
- **`Dockerfile.demo` + `render.yaml`** run `app.demo.allinone`: **one process** serves the API, runs the job
  worker and scheduler, and hosts the mock platforms on loopback.
  - `mock-platforms` is aliased to 127.0.0.1 inside the process.
  - The SSRF guard still refuses loopback for caller URLs.
- **Supabase** provides Postgres (session pooler, port 5432, for LISTEN and session advisory locks) and S3 Storage.
- **Refusals at start:** the demo refuses to start unless `SIMULATION_MODE=true` and `APP_ENV` is not `prod`.
  `APP_ENV=demo` refuses the repo's dev placeholder secrets.
- **Secrets:** `API_TOKEN` is generated by Render.
- **Rate limit:** 120 requests/min per client IP, with `TRUSTED_PROXIES` set for Render's proxy hop.
- Demo destinations are seeded and certified at start. `POST /api/v1/sim/reset` resets them.

## Consequences
- $0 hosting.
- Cold start after an idle period; it is measured and stated in the form.
- Real Lemmy and Ghost are not in the demo. Reviewers run them locally with `docker compose up`.
- Deploy steps: `deploy/render/DEPLOY.md`.
